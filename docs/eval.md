## Hard set + double-read gate (2026-10-28, repeat 3, $1.51)

24 harsh Pillow variants (perspective, motion blur, low light, low-res,
rot90/rot180, glare, crop) of the S2/S3/A photos, each run 3 times, plus
3 runs of every normal image. Regenerated from the run log with
`claimlens eval-report out/hard_eval_20261028T123219Z.json` (recompute,
no new calls). The hard set ran 23/24 cases: the run aborted past the
$1.50 `--max-cost` cap ($1.51 total), and the 24th case kept 1 run, so
the pair simulation covers 66 hard pairs + 30 normal pairs.
